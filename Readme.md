L-System
========

Rust library for Lindenmayer systems (string rewriting) and a small turtle demo.

## Layout

```text
projects/
  crates/
    lsystem/             # Rust library
  packages/
    homepage/            # demo site (VMZ host shell)
```

## Build

```bash
cargo test --release
# or: pnpm test
```

## Web

```bash
pnpm dev:web
```
